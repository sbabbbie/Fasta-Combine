Good to know
  • A file with no > header line (like a .seq file from the sequencing facility) is named after the file.
  • Chromatogram files (.ab1) and Word documents can't be read. Export the sequence as FASTA first.
  • Two different sequences with the same name get _2, _3 added so every name is unique.
  • Letters that aren't DNA bases are flagged but left in, so you can decide what to do.
